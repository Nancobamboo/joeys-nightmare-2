Project Code Style

1) Naming
- Public fields/properties/methods/classes: PascalCase
- Private fields: m_PascalCase
- Local variables: camelCase
- Constants: PascalCase

2) Comments
- Do not write comments.

3) Formatting
- Preserve indentation style of each existing file
- Prefer readability; no hard line-length limit
- No trailing whitespace

4) C#
- Use explicit access modifiers
- Avoid var when type is non-obvious
- Use readonly where appropriate
- Do not use foreach for value type arrays; use for loop instead

5) JSON
- Use float/double as needed; do not force integers

6) Card Effects
- When a CardEffect needs to call a method in UIGamePhaseControl, implement the specific method in a partial class UIGamePhaseControl at the bottom of the CardEffect file
- The wrapper method in UIGamePhaseControl.cs should extract parameters from object[] and call the partial class method
- Example: YElectric.cs implements TakeAllEnemyDamage(int damage) in partial class, UIGamePhaseControl.cs has TakeAllEnemyDamage(object[] paraArray) wrapper
